# Data Exploration with Pandas

This project is a personal exploration of **Post-University Salaries of Graduates by Major** using **Pandas**. The goal was to practice data analysis and get familiar with common operations like filtering, grouping, and summarizing data with pandas.

---

## Overview

- **Dataset:** CSV file containing graduate salaries by major
- **Tools:** Python, Pandas, Google Colab
- **Focus:** Basic data exploration and analysis for self-practice

Example analyses performed:

- Viewing top-paying majors
- Grouping salaries by major categories
- Calculating average salaries
- Handling missing or non-numeric data

---

## How to Run

1. Open the notebook in **Google Colab** or VS Code with the Colab extension
2. Upload the CSV file to the session
3. Run the notebook cells sequentially to reproduce the exploration

---

## Google Colab in VS Code Tips

When using Colab notebooks inside VS Code:

- Sometimes you may need to **reset the connection**:
  1. Open the **Command Palette** (`Ctrl` / `Cmd` + `Shift` + `P`)
  2. Select **Colab: Remove Server**

- This clears stale runtimes and allows you to reconnect to a fresh Colab session.
- Good reference: [Colab VS Code User Guide](https://github.com/googlecolab/colab-vscode/wiki/User-Guide)
